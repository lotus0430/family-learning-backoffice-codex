# 数学家庭练习推进与提醒规则

## 家长确认的协作方式

**modifier**：GPT-5（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

本规则随基础包提供，但不因初始化或出现一份错题自动启用。只有家长已经确认具体学科、知识范围、总体负担、推进方式和暂停条件，并已建立有效计划与台账时，才进入持续推进状态。

启用后，数学日常练习按已确认计划、实际完成轮次和还课结果持续推进。“每日练习”表示持续安排与跟进，实际不要求每个自然日都做。家长进入项目时，AI应像检查待办一样主动检查并报告练习状态，不能等家长再次提出“出题”才处理。适用中的具体范围、题量、时长、起始轮次和暂停状态存于私人计划与台账，不在规则中写入孩子作答等运行资料；单次材料、单次错误或 AI 建议不能代替家长授权。

## 每次进入与当天提醒

1. 读取数学家庭练习的计划与台账、推进待办，优先检查已有材料和还课记录，避免漏看已入库作答或要求重复提供。
2. 当天首次沟通，主动说明当前轮次、是否有已备好的待做练习、是否等待还课，以及下一步。即使本次主要处理其他学科，也应简短带出；若家长明确要求只处理当前事项，则尊重当次要求。
3. 同一天已有明确反馈，不机械重复提醒。新还课、核对完成、下一份备好或家长约定稍后提醒时，更新状态并报告新进展。
4. 将最近提醒日期、提醒内容、家长答复及当次下一动作记入私人台账／推进待办。只读到了任务不等于已向家长提醒。

## 按状态推进

| 当前状态 | AI动作 |
|---|---|
| 已有待做练习 | 指向已有文件，告知内容、题量和时限；优先完成当前轮，不因日期变化再出一张 |
| 是否完成未知 | 先查已有材料；仍未知时最小询问是否已做，不把未还课写成未完成 |
| 家长说已做，具体作答未回流 | 记录家长说明，提醒回收必要结果；不推定正确或已掌握，也不无依据安排补练 |
| 已收到还课 | 归档，保留首次作答与订正链；独立双路核对后更新实际用时、错误及提示情况 |
| 结果已核，计划适合进入下一轮 | 在已确认范围、负担与方式内主动准备下一份；可复用已备题，必要时据结果修改，交付前双路核对。无需再问“要不要出题” |
| 当天休息／延期 | 保留当前轮，记录当天决定和已约定的新日期；下次进入时继续跟进，不积累每天一份的欠账 |
| 家长明确暂停整个计划 | 记录暂停，不再主动催练；等家长明确恢复 |

单次只主推一份当前练习，除非家长明确要求提前多日备题。已经预备多份时，保存顺序；还课结果若显示后续预备题需调整，应更新版本并重核，而不是跳过反馈照发。计划使用日期、原始文件日期与实际作答日期分开，延期不覆盖历史。

还课有局部待核时，按证据边界处理：不以未决项决定新的针对性训练；其余已确定信息足够时，可继续已确认计划的常规内容。若下一步确实依赖缺失信息，再提出最小核对问题。

## 出题机制：分来源保存，统一选题

### 共同输入

每次生成或调整下一份练习前，必须同时检查：

1. 学校作业、课堂练习、测验新入库后经核对确认的孩子错题及订正；
2. AI家庭练习还课后经核对确认的孩子错题、正确表现、自查与提示情况；
3. 已有旧错题的后续独立回访记录、最近实际练习时间与到期回访候选；
4. 教材知识点覆盖、当前已确认的教学进度、家长批准的范围和时间预算。

两类错题在各自台账中保存并分开统计，通过一个统一错题池入口关联，出题时共同参与选择。统一池保存原条目引用、知识点、后续练习关联与回访状态，不另复制一套易冲突的原答或判定。按原材料编号＋题号／小项＋作答版本识别同一条证据，避免多个索引重复计算。

新学校材料完成核对后，即使家长当次未提“家庭出题”，也须同步统一池入口及受影响的候选项。家庭还课同样更新；若当前预备题已不能回应新的明确需要，在已授权范围内调整后重核，保留旧版本记录。

“AI家庭错题”指孩子做AI编制练习时实际发生且已核对的错误。未做的AI变式、AI出题错误、AI参考答案错误、已撤回的误判和识别未决项都不能充当孩子的确定错题。教师或家长反馈与AI核对的证据身份分别保留。

### 每轮选择与取舍

先限制在家长已确认的知识范围与总时长内，再按本轮目的选择：

- 近期新确认、订正后仍不符或多次独立作答重复出现的点，优先查看；需要理解支持时不能仅加同类题。
- 已订正但尚缺隔日独立证据的点，在合适间隔安排回访，不能因订正成功就移除历史，也不能每次全部重做。
- 已到回访窗口的旧知识，结合实际练习日期穿插；因休息积压的候选重新排序，不堆成当天必做任务。
- 当前阶段尚未覆盖的教材内容，以及已有课堂证据的新内容，保留代表题；无旧错记录也可以出题。
- 已有稳定独立表现的点降低频率，保留少量维护。不能让统一池变成“历史错题越多，每次题量越大”。

固定比例、复习间隔和降低频率阈值属于当前私人计划中的试行参数，不能当成通用定律或未经确认的新强度。超出当前阶段的错题先纳入池并注明待后续阶段，不因刚入库就扩大复习范围。

### 每道新题的可追溯依据

制作记录须能回答：本题为何入选（补覆盖／当前内容／旧错变式／间隔回访／保持熟练）、教材位置、关联源题或前次家庭题号、与旧题的变化、参考用时。没有旧错来源的题明确写覆盖用途，不编造错题依据。

同一知识点跨学校与家庭重复出现时可关联成一组候选，但保留不同原题的数量关系、作答条件、提示程度和熟悉度。不能仅凭知识点标签把不同错误归为同一原因。

题面与配套答案独立双路核对通过后交付；收到实际作答后重新完成还课核对。新结果回写来源台账与统一池关联，再用于下一轮。只有“出了题”没有作答证据时，不能更新为掌握或已回访成功。

## 授权与质量要求

还课的完整转录、出题／批改身份、家庭错题独立记录和PDF清理，统一遵守[AI家庭练习还课与来源区分规则](AI家庭练习还课与来源区分规则.md)。制作阶段核对通过不能替代收到孩子作答后的独立双路核对。

- 持续出题授权以家长已确认的计划为边界。按结果在该范围内选择题型、复用材料、调整题量以符合已定时间预算，可直接执行。
- 明显增加总负担、超出已确认知识范围、安排新的讲解干预或改变整体节奏，需家长确认。错误原因和长期能力判断仍按项目原则处理。
- 新编、修改题目及配套答案，以及孩子作答的正确性判定，继续遵守独立双路核对要求；核对通过前不作为最终材料交付。
- 已出题、已交付、家长报告已做、已收到原始作答、已核对和订正完成分别记录，不互相替代。

## 两种跟进分开

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-22

材料准备链回答“有没有合适且核对过的题”，结果回收链回答“是否实际做了、表现如何”。材料准备完成可以关闭该批制作询问，不能同时关闭练习执行提醒。

保留一条持续推进待办作为入口，各批结果待办负责具体回收。批次待办完成后，持续推进入口应指向下一轮；计划只在家长明确结束或暂停时停止相应提醒。

本机制在家长进入会话时执行，不代表后台定时生成、主动推送或对外发送。所有计划、练习、提醒日志与作答记录均保存在当前家庭的本地工作区。
