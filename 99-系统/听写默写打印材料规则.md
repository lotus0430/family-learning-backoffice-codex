# 听写默写打印材料规则

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

以下是可选的打印样式，适用于家长要求制作某课“看拼音填写”材料时；先确认该家庭的指定范围、是否合并教材扩展项和版式偏好。一次制作请求只授权制作本次材料，不授权以后自动加练。段落默写等其他题型按实际要求排版。

## 版式参考

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

本包不含样张 PDF。按下述文字规则生成学生页与另页家长答案；若家长提供样张，只参考已确认的版式，不沿用样张的字词或拼音。

## 先核来源与范围

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

1. 从已入库的老师通知和所用教材确认课次，直接查看该课对应的**词语表、识字表、写字表**原页，记录教材页码及各项数量。已在资料库中的教材不要求家长重传。
2. 若老师重点依赖课本标记，检查是否已入库清晰的标记照片；缺少时向家长说明范围缺口并请求补充。收到照片后逐页核课次、标记词及跨页续接；颜色、圈线或批注的含义不明时向家长最小核对，不自行规定某种颜色就是老师重点。
3. 先分列老师明确指定项、课本标记项和教材表内项。是否把教材扩展项与老师重点合并打印，由本家庭家长确认；确认合并后逐项取并集、去重并保留来源关联。缺少独立词语表或写字表时如实说明，不虚构表项。
4. 家长答案页标明各项的真实来源，不把教材扩展项写成老师指定词目。拼音逐字核对，尤其检查多音字在本课语境中的读音；原页不清或范围冲突时提出最小核对问题。
5. 单字表里的多音字按本课实际语境标音：先找该字在标题、正文或词语表中的用法，再核对规范词典；同课存在多个读音且未指定语境时分别标明或先核范围，不用工具给孤立汉字的默认音猜测。

## 学生打印页的默认版式

- 用A4、黑白友好、直接打印的PDF；在字能正常书写、拼音能清楚辨认的前提下尽量节省纸张。
- **每字上方标带声调的拼音，下方留空白田字格**；一个字对应一个格，词语的多个字连排，格中不印答案。
- 词语顺序打乱，不照搬教材词语表；单字项目也可打乱。同一行横向排多个词或字，放不下时自动换行；不做一词一整行的稀疏布局，不加序号。
- 可用简短分区标题标明词语表、识字表、写字表的来源和数量，但学生页任何位置都不能出现待填汉字答案。重复字的说明只写数量，不在学生页泄露该字。
- 单独生成同序的家长答案页；答案与学生打印页不合并，以免整份打印时把答案交给孩子。

## 交付前检查

先按`材料处理规则.md`的“AI编制练习材料的交付前双路核对”完成制作方与独立Agent的内容检查。两路均须核对词语、单字与教材原页一致，去重后仍覆盖两张单字表的全部字；逐词核对拼音和多音字的实际读音，检查词序、拼音与格子逐字对齐及学生页无答案。解决差异并修正后，将最终PDF渲染成图片逐页查看，确认没有裁切、重叠、缺字或过小的格子，再提供学生版和家长答案的文件链接。记录教材来源和“老师指定／家长扩展”的边界。
