# 绘本朗读打印材料规则

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

本规则提供将已提供绘本整理为朗读打印页的参考格式：旁白与人物对白分开，逐句标明角色。制作前由本家庭家长确认任务范围和版式；制作打印页不等于孩子已朗读、已还课，也不自动安排额外练习。

## 版式参考

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

本包不含原家庭的样张 PDF。可以按下列文字规则制作：A4 横向、依原书页序、旁白与对白分开、逐句标角色；具体页数和栏数由当前绘本篇幅决定。

## 先核绘本原件与角色

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

1. 先根据本次老师通知、家长确认和已入库材料确定**实际指定的绘本**，查同系列编号及缺号；不能把旧材料或其他故事直接当成本次范围。老师指定范围与资料库中可用的绘本分开记录。
2. 逐页查看原始绘本图片或PDF，同时对照已有转录。按书页顺序保留每一句英文、标点和重复句，注明原书页码；封面、旁白、气泡对白及内心话分别识别。已有文字转录可以帮助检索，**不能代替原图判断谁在说话**。
3. 根据气泡尾部、人物位置、颜色和前后情节给对白或内心话标角色；把没有气泡的背景叙述标为“旁白”。角色名称是为朗读而加的派生标注，不冒充原书印字。某句无法可靠区分具体人物时，用不作推定的中性标签（如“孩子”），说明不确定处并按材料处理规则询问家长是否核对；多个气泡尾部指向群体时可用群体名称，不能硬指定单一人物。

## 打印页默认版式

- 用便于直接打印的A4横向PDF。篇幅允许时，每本绘本独立一页；需要增加页数时优先保证字号和角色辨识度，不为压成一页而把旁白、对白合成段落。
- 依原书页码顺读，同一书页内逐句排放。可分左右栏，但栏首清楚标出页码范围，换栏后仍按原书顺序；不要把多个书页的句子无标记地接在一起。
- 旁白用独立的灰底或同样清晰的非彩色样式；人物对白和内心话逐句显示文字角色名，可再用不同颜色辅助区分。即使黑白打印，也应能凭文字标签分辨角色。书中重复的原句照实保留。
- 页眉写书名，页脚说明角色标签是依据原图添加；原书插图和封面仍以原件为准。含义未明的角色用中性标签或备注，不用版式美化掩盖不确定性。

## 交付前检查与关联

逐页对照原绘本检查英文原句、标点、顺序、页码和角色；尤其检查同页既有旁白又有对白、多人交替、合说及内心话的位置。渲染最终PDF，逐页查看字号、灰底、换行、裁切、重叠和黑白可读性；重开PDF核对页数与文字。若同一绘本另有AI伴读稿或角色对读材料，同步核对它们的旁白与角色分工，避免与打印页冲突。更新关联的材料或待办记录，保留原绘本不变，并将打印页作为派生材料记录。
