# 教材与进度关联规则

## 基本分工

- 教材提供相对稳定的知识地图。
- 试卷、作业、默写、通知、孩子口述和家长观察提供学校实际教学进度证据。

家长提供教材文件或纸书照片进入系统后，AI负责在已提供范围内建立目录、单元、章节和页码索引。后续处理材料时，应主动检索并关联已有教材，不要求家长重复提供已入库的对应课本页。

## 教材来源边界

**date**：2026-10-22

v0.1 只处理家长已经提供的教材文件、纸书照片和学校资料。缺少教材时，说明缺哪一册或哪一页，以及对当前判断的影响，等家长自行提供；不主动获取、下载或转发电子教材，也不索取群账号、登录凭证或请求鉴权信息。已提供文件的版本仍须对照封面、版权页、目录、页码和纸书照片核验；无法确认时保留待核，不凭文件名认定同版。

## 作业核对前查全本课教材

作业出现课文名、篇名、作者、节选出处或“对比阅读”时，先从已入库教材定位对应课次，再查看该课的正文、注释、课后练习、阅读链接及相邻页。另一篇作品即使不在目录中单列为课文，也可能以课后阅读链接的**节选出处**出现；不能只搜索目录标题或正文第一页，就记“原文未入库”。

按“作业题面用词 → 教材目录与全文检索 → 课文及课后相邻页原页复看 → 其他已入库材料”的顺序查找，并记录教材版本、印刷页码、PDF页码及证据所在栏目。PDF搜索无命中、提取文本不全或标题不一致时，仍要目视核对相关课后的页面；只有这些检查完成且确无对应内容，才标记原文缺失并向家长询问。教材只收录节选时，依据仅限该节选，不把它当成整部作品或教师标准答案。

发现此前因漏查教材而设的“原文待核”时，保留当时判断和更正过程，依据新找到的原页重新进行独立双路核对；解决差异后同步材料记录、索引及家长前置卡的 HTML／Markdown 状态，不静默覆盖旧结论。

## 关联关系

材料与教材是多对多关系：一份材料可以涉及多个单元；一个单元可以关联多份作业、试卷、通知和事件。必要时逐题建立关联。

每条教材关联至少记录：

- 教材名称和版本；
- 单元、章节和页码；
- 关联对象；
- 关联依据；
- 置信度：`high`、`medium`或`low`；
- 是否需要家长确认。

## 进度证据等级

```text
未观察到
→ 已在材料中出现
→ 疑似正在教学
→ 多份材料证实正在练习
→ 已检测
→ 已进入后续复习
```

知识点出现在材料中，不自动等于老师正在新授。遇到综合卷、旧知识复习、教辅题或跨单元题目时，应保留多重关联并说明不确定性。

## 请求补充材料的边界

只有现有资料缺页、模糊、版本不一致，或内容来自尚未提供的讲义、教辅、校本资料时，才请求家长补充。请求必须说明缺什么、为什么需要，以及不补充会影响什么判断。
