# 家庭学习后勤文件夹｜第一次使用

## 1. 打开文件夹

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-26

把下载的压缩包完整解压到本机，为一名孩子保留一份独立文件夹。用 Codex 打开**包含 `AGENTS.md` 和 `00-收件箱/` 的那一层目录**，输入：

> 初始化一下文件夹

说“初始化文件夹”也可以。

Codex 会问孩子的称呼、年级、学期、已知的教材版本，以及是否允许只保留内容完全重复文件中质量较好的一份。教材版本不知道就回答“不知道”。姓名、班级、学号暂时没有也可以继续；以后遇到只针对特定孩子的通知时再补。

看到 Codex 明确回复初始化完成，再放第一批材料。一个文件夹只服务一个孩子；第二个孩子请另复制一份。

## 2. 先用一条真实作业走一遍

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-26

找一条最近的老师作业通知，以及它对应的题面截图或照片，放进唯一的 `00-收件箱/`。然后对 Codex 说：

> 处理一下收件箱。这是孩子最近的作业；请告诉我你看到了什么、还缺什么。

如果放进去的是旧材料，请直接说明它原来是哪天或哪个时间段的；不知道就说不知道。不要因为今天放入，就把旧作业当作今天新布置的。教材文件或课本照片可以由你自己提供，Codex 只核对你提供的版本与内容。

处理后先看 Codex 的简短汇报，再检查三处：`02-原始材料/`是否保留照片，`03-完整转录/材料索引.md`能否找到文字和来源，`05-待办/待办索引.md`是否写清下一步。若题面可见，家长备用的解题提示在 `03-完整转录/家长前置卡/`；它不是孩子已经答对的证明，也不表示必须给孩子讲解。

## 3. 每天回来与作答回收

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-26

回到同一个文件夹，问：

> 今天还有什么待处理的？

孩子完成作业后，把作答照片放进 `00-收件箱/`，说“这张是刚才那份作业的作答，处理一下收件箱”。Codex 应把照片接回原题和待办，分别保留题面与作答。遇到看不清的字、题号或批改痕迹，请你看纸本确认；核对未完成时，先不要把 AI 的判断当作最终结果。

如果孩子后来订正，再把订正版照片放入同一个收件箱，并说明它是对哪份作业的订正。检查初次作答有没有保留、订正后哪里变化了，以及老师复批是否真的有证据。**订正了不等于老师已批回，也不等于孩子已经掌握。**

## 4. 家长负责的决定

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-26

Codex 可以整理材料、列出疑点和提醒下次要回收什么。孩子为什么错、是否需要讲解或加练、练多少，仍由你结合纸本和实际情况决定。发现转录或关联错了，指出原件和具体题号，让 Codex 保留更正记录并修正相关文件；需要暂停时直接说“先停止处理，请列出已经移动和生成的文件”。

这个本地文件夹不会自动读取微信群，也不会在你没打开 Codex 时主动推送提醒。文件存在本机不代表 Codex 处理内容时只在本机运行；放入孩子资料前，按你对当前 Codex 服务的接受程度选择材料。群聊反馈问题时，不要公开孩子姓名、班级、学号或作业原图。
