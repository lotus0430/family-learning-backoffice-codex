这是一个交给 Codex 使用的本地工作区，不是只做错题集的文件夹。它默认承接一名孩子的完整家庭学习后勤链：

```text
群通知／家长口述／作业与试卷／教材资料
→ 收件、查重和保留原件
→ 完整转录与必要的独立复核
→ 学习事件、待办和教学进度
→ 已确认错题与知识点对齐
→ 家长确认后的后续练习
→ 还课、复核、回访与调整
```

“默认全链路接管”表示 Codex 不要求家长先选择功能模块；它仍必须遵守事实与判断边界。错因、能力、讲解、加练、复查强度以及长期计划不能由 AI 擅自决定。

## 第一次使用

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-26

按[第一次使用](开始这里/第一次使用.md)一步步操作；下面是简要顺序。

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-22

1. 家长在本机选择一个可读写的空目录或专用目录，作为这名孩子唯一的工作区根目录。
2. 把本包内容放入该根目录，在 Codex 中打开根目录，并发送“初始化一下文件夹”（“初始化文件夹”也可以）；[启动入口](开始这里/Codex初始化指令.md)提供同一句话。
3. Codex 检查并只保留一个根级`00-收件箱/`，随后按[家庭初始化问答](开始这里/家庭初始化问答.md)一次性询问必要事实与重复件处理授权。
4. 初始化完成后，家长把图片、PDF、文档或文字材料放入`00-收件箱/`，再说“处理一下收件箱”。
5. 初始化完成时按[初始化验收清单](开始这里/初始化验收清单.md)核对；首批材料处理后再核对材料索引。没有真实证据的事件、错题、进度或练习不得为了填满目录而创建。

一个工作区只对应一个孩子。另一个孩子应另选根目录、复制一份独立工作区，不能只在同一收件箱里用姓名区分。

## 初始化只问什么

**date**：2026-10-20

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

初始化不是功能选择器。系统默认启用整套后勤能力，只询问：

- 本工作区对应孩子的年级、学期和协作称呼；班级、姓名、学号若已知可一起提供，用于核对老师截图中的定向通知，暂未提供时遇到具体通知再补；
- 已知教材版本；家长不知道时直接回答“不知道”，由 Codex 在内部标为待核版，以后从课本或可靠材料核版；
- 确认完全重复文件如何处理的一次性授权。私人材料默认只用于当前家庭工作区，公开使用另行征得家长同意；初始化不问这一默认边界。

第一批模式与大致时间范围不属于初始化问题，也不默认按新材料处理。收到材料后先看原件和家长已经给出的说明；若仍不清楚且会影响截止事项、考试归属、教学进度或顺序，才询问一个必要的概数。概数记在材料索引的收件组中，不能伪装成每份材料的精确日期，也不另建批次目录。

## 日常入口

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-22

- “处理一下收件箱。”
- “这批是以前积累的材料，大概到上学期结束，具体日期不清楚。”
- “这张卷子是今天带回来的，和之前没写完的事项有关。”
- “今天有什么待处理或已经到期的事情？”
- “把这份作业和教材、最近教学进度关联起来。”
- “先整理事实，不要安排练习。”

教材文件或纸书照片由家长从自己的渠道提供。v0.1 负责本地核版、索引和教学进度关联，不提供电子教材查找、下载或转发步骤，也不索取群账号或下载鉴权信息。

## 能力与触发边界

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-19

**modifier**：GPT-6（OpenAI Codex Agent，Default 模式；小版本未暴露）

**date**：2026-10-20

- 通知、作业、试卷、教材、错题和家庭练习属于同一条链，不拆成互相失联的模块。
- v0.1 的家长作业前置卡只用于孩子要逐题作答的练习、作业和试卷：题面可见或可从已入库材料准确定位时按需生成；简单题用会话与 Markdown，多题／多页且需原图定位时再做 HTML。绘本朗读、知识点页、单纯阅读／背诵／预习及通知附的指导示例不自动触发卡片；其中若另有实际作答题目，只对题目做卡。其他材料仍正常归档和处理；卡片不参与孩子答案的判定。
- 含孩子作答的材料按规则完整转录并独立双路核对；无法独立启动第二 Agent 时，必须明确报告未完成，不得伪造双路结果。
- 数学家庭练习规则与模板随包提供，但只有家长确认具体学科、范围、负担与推进计划后，才建立持续练习台账并主动跟进。
- 未来事项只在 Codex 会话中被主动带出；本包本身不能后台监听群聊、读取未提供的聊天记录、定时推送或自行访问外部账号。
- 原件只写月日、未写年份时，按家长确认的默认口径补为收件当年，并标明年份是默认推定；若有明确历史年份或冲突证据，以证据更正。原件连月日都不明确时保持`unknown`。不因文件修改时间或批次概数推定布置日期、考试日期或学习进度；按收件当年补年份也不等于认定任务仍在进行。
- 首次处理前，Codex 应核实当前环境能否读取输入格式、写入工作区、打开生成的 HTML/PDF，以及能否启动真正隔离的独立核对者。某项能力不足时，保留原件、记录已完成步骤与阻塞项；不得把未完成的核对或渲染标为通过。
- 本包提供规则、目录与模板，没有自动监听、定时任务或确定性的一键处理程序。复杂图片、手写、PDF 和并发收件仍依赖当次 Codex 的实际能力与人工复核。
